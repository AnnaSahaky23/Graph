# Graph Algorithms in C++

A simple C++ program that implements basic graph algorithms using an adjacency list.

## Features
* **DFS Traversal:** Explores graph vertices recursively.
* **Connected Components:** Counts how many separate parts the graph has.
* **Articulation Points:** Finds vertices whose removal increases the number of connected components (cut vertices).

## How to Run
Compile and run the code using your terminal:

```bash
g++ -std=c++11 main.cpp -o main
./main
